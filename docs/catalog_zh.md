# 数据目录

原始数据集详情与分析产品的数据集区域使用同一浏览组件及共用详情样式，统一地址、元数据、Item 列表及预览操作。

可按发布节点筛选数据集，并与类别及文本搜索组合使用。每张卡片显示所属节点。节点归属来自目录元数据，无法识别的节点会明确标注。

“节点列表”页面（`/nodes/`）展示数据中心与共享中心，包含连接状态、数据集摘要、数据量及节点上报的资源指标。

通过类别筛选区分“原始数据集”和“数据分析产品”，每张卡片标明所属类别；类别筛选可与文本搜索组合使用。

目录首先展示可搜索的数据集卡片列表，卡片包含标题、描述和标识。打开卡片后查看 Item，通过返回按钮回到保留搜索条件的数据集列表；仅在打开数据集后请求其 Item。

在 `/catalog/` 浏览当前 Union 发布的数据集，包含成员数据中心和共享中心的数据产品。目录可搜索名称、描述及标识；点击数据集后按需加载 Item 和 Folder。

每个数据集展示说明、公开元数据、DACP 地址及已启用的 Union S3 地址。每个 Item 可复制 DACP URI；提供 bytes 视图且 Union 启用 S3 时，可使用“复制S3地址”；DACP 复制按钮为“复制DACP URI”。Item 操作不提供临时链接入口。访问仍须信任服务证书。

预览最多展示 20 行、64 列，每个单元格最多 512 字符；bytes 预览最多读取 4096 字节，二进制以最多 256 字节的十六进制表示。专用科学视图展示结构元数据，不将数组强行展开为记录。读取权限仍由 DACP 服务决定，目录可见不保证内容可读。

目录请求限制在已配置 Union 广告的数据集内，不接受任意远程源。目录缓存 30 秒；页面仅在打开、操作或手动刷新时加载。单次列表最多显示 1000 个 Item。

运维：完成网络启动后执行 `bin/conet catalog-up`，会在 Union 空闲时启用其 S3 服务并准备目录签名账号，然后执行 `bin/conet restart-web`。七个科学节点无需启用 S3。不要向浏览器或应用程序包提供长期密钥。
