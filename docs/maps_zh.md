# 案例地图

三个案例的地理地图统一采用 **天地图 JavaScript API 4.0**：

- 淤地坝：分析区域选择图及结果图的地理底图。矩形框选、多边形绘制和顶点编辑使用 WGS84 经纬度坐标。
- 灾情应急：地理底图、选区与影响要素叠加。灾前／灾后影像及对比滑块展示案例的合成输入影像。
- 天文观测：可交互的地理地图展示三个天文台在配置中的示意位置。天区选择、星源分布与颜色分析继续使用 ICRS 天球坐标；地理地图不能代表星空。

共用的浏览器端加载器为 `web/assets/tianditu.js`。部署时设置其浏览器应用 Key，并在天地图控制台配置允许的域名。浏览器 Key 对访客可见。访客需要能访问天地图 API 和瓦片服务。SDK 加载失败时界面给出提示，不自动换用其他地图提供方。CONET 不代理或缓存地理瓦片。

案例输入及灾情结果要素均为合成数据。天文台位置来自演示配置，并非经过核实的真实台址。地理底图不能证明科学结果有效。

地理底图模式的 PNG 下载仅包含**分析叠加层**，图中有明确标识，不包含天地图瓦片。合成影像／地形模式可以导出本地影像及叠加结果。如需完整地理地图，可使用浏览器截图或打印工具。

修改加载器或后端路由后，重启本地 Web 进程：

```bash
bin/conet restart-web
```

该命令不会部署远程官网，也不会重启数据节点。

案例页面初次打开或刷新时不自动恢复历史分析，结果区保持空白。提交新分析后，完成时展示当前结果；也可手动点击历史任务查看对应结果。重新提交时清除上一次结果，避免误认。
